## 发布

`publish_sample.py --revision <完整 Git 提交号>` 在既有服务器上按固定提交下载视频与封面、核对文件长度和 SHA-256，备份目录后更新同一条视频记录。其他视频条目须保持一致，不需要重启应用。

生成服务返回的临时下载地址和账户信息不保存在此目录。
