# 经藏文化诵读更新

本次按站主要求补充药师咒、大悲咒，以及观成法师原版诵读。发布目标为 tripitaka.shop，保留投资站附带的文化页面。

## 使用方式

- 药师经、金刚经、心经、地藏经以及已核实的法华经集数，优先显示观成法师原版播放器，默认请求 2 倍速。状态栏显示播放器实际确认的速度；可随时改回原速。
- 药师经正文原有结尾“皆大欢喜，信受奉行”保留，之后追加“回向文（诵读附录）”及视频末尾四句回向。设备朗读会接着读完附录。
- 药师咒、大悲咒支持国语、粤语设备声音及 108 遍完整计数。每篇全部读完才增加一次，暂停、失败、跳读不多计。已完成遍数保存在当前浏览器，满 108 遍停止。
- 有原版录音的页面仍可展开“设备朗读”使用国语或粤语合成声音；切换播放器时停止另一种声音。

- 法华经播放器仅列当前核实的集数；不把讲经视频标成诵读，不声称全 28 集已齐。
- 心经使用寺方公开的粤语导诵音频。大悲咒寺方另有导诵，但来源未明确标注粤语，因此未冒充为粤语录音。
