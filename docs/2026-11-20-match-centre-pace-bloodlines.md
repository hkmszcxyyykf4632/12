# 比赛中心分析、赛马步速模拟与著名血统

## 本次变化

- 比赛中心每场新增“本场分析”入口。英超、西甲、意甲、德甲、欧冠共用每日赛事的战意依据、赛后验证、赔率变化、确认首发比较、天气及连续战绩模块。
- 分析按赛事、主客队、比赛编号及开球时间核对。完场后只核对已有赛前记录，不补写事前判断。
- 远端球队赛程无法取得时，补入网站已收录的完场往绩，逐场保留来源，并继续尝试核对上一场及最近同对手的首发。公开数据不足时保留空项。
- 赛马详情增加“步速与跑位模拟”：播放、暂停、重置、1/2倍速度、进度拖动、偏慢/正常/偏快三种步速情景。
- 赛马预测的输入加入同一份步速资料。页面把既有首选、关注马与情景影响对应显示；切换情景不改写原预测。
- 香港赛马导航增加“著名血统与香港马匹”，介绍丹山、鞍匠井、淘金者、暴风猫、沙彪、北地舞人，区分父系及母父支系，提供搜索、马匹档案链接、血缘路径和逐条来源。

## 数据与计算

步速只读取现有马匹档案，不增加后台抓取任务。采用本场日期之前最近六次有效沿途走位，排除退赛、重复、名次与沿途终点不符及本场/未来记录。近期权重6至1；同场、同跑道类型且途程差不超过400米时权重加倍。至少两次记录才归类跑法。首个记录点可能并非400米。

动画是条件推演，没有计算真实速度、完成时间或夺冠概率。快慢情景参数在页面说明；不能把终段图示当作预测名次。赛前模拟保存于私有状态目录 `racing-pace/`，包含时间、比赛身份及完整性校验。赛后使用保留的赛前版本；无赛前记录时标为回看推演。正式赛果到齐后对照早段跑法一致性，与胜负命中率分别展示。

血统祖先库核对日期为2026-11-20。香港马匹来自已同步的马会目录；祖先关系来自牧场、拍卖机构及登记资料。只纳入关系链连通且有来源的马，未列入不代表没有该祖先。同一匹马可属于多个上游家族，也可同时有父系和母父关联，数量不能简单相加。当前是六个代表血系及部分核对支线，非全部纯血马族谱。
