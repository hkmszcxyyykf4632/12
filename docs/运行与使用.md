# 本地运行与日常操作

## 准备与启动

需要 Python 3.12 或更新版本。先取得仓库并进入 `footballknow`。Node.js 只用于前端测试；网页本身不需要构建步骤。

```sh
git clone https://github.com/hkmszcxyyykf4632/12.git
cd 12/footballknow
python -m venv .venv
```

Windows PowerShell：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe manage.py init-admins
.\.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8765
```

Linux/macOS：

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python manage.py init-admins
.venv/bin/python -m uvicorn server:app --host 127.0.0.1 --port 8765
```

打开 `http://127.0.0.1:8765`。首次管理员初始化会在源码目录的上一层生成私密账号文件；已有账号不会被覆盖。源码包里的公开快照可用于首次展示，更新时间可能较早。

另外一个终端在同目录运行 `.venv/bin/python worker.py`（Windows 使用 `.venv\Scripts\python.exe`）启动自动同步。关闭本地同步进程后，页面只显示最后的快照。`FOOTBALL_STATE_DIR` 可指定私人状态目录；线上设置为 `/var/lib/footballknow`。

## 页面使用

先选择英超、西甲或欧冠，再进入球队。球队档案中可查看球员、中文名、最近二十场、转会与领队；点击赛果进入比赛详情。比赛中心支持筛选；数据榜单可切换积分、球员和球队指标。

点击“关注球队”后，在“我的关注”查看所选队伍的比赛。关注、手动赔率和模拟账户存于当前浏览器，换设备不会自动同步。模拟记录应定期通过页面导出；导入前会要求在页面核对，已有记录不静默覆盖。

管理后台登录后进入 AI 设置，粘贴 DeepSeek API 密钥并保存。默认地址和模型已配置；浏览器不会收到保存的完整密钥。到球队的下一场分析，点击生成／更新结论。默认显示两至三段，展开“更多详细资料”查看概率、阵容证据与报告细节。刷新比赛数据不会自动调用收费 AI。

## 常用手动同步

```sh
python sync_live.py
python sync_rankings.py epl standings
python sync_rankings.py laliga leaders
python sync_match_details.py ucl --limit 80
python sync_odds.py epl
python sync_odds.py sources
python sync_laliga.py catalogue
python sync_ucl.py live
```

以上 `python` 应换成项目虚拟环境中的解释器。`sync_rankings.py` 支持三赛事和 `standings`／`leaders`；`sync_match_details.py` 与 `sync_odds.py` 支持三赛事。球员名称来源有限，暂用音译会保留标记，不会自动视为已核实的官方译名。
