# 企业版升级说明

本次升级包含同步引擎、界面和新功能三部分，源码都在 `footballknow/`。尚未部署到腾讯云，线上仍是 2026-11-16 22:08 的版本。

## 同步

- 全部 25 项任务统一每 60 秒检查；网页每 60 秒读取全部快照，顶部显示倒数，点击可立即同步。
- 来源请求带 `ETag`／`Last-Modified` 条件头，未变化时不重新下载。
- 连续失败自动退避，最长 15 分钟；`FOOTBALL_SYNC_SECONDS` 调整统一间隔，`FOOTBALL_SYNC_OVERRIDES` 为个别任务单独设定。
- 新增 `/api/health`；`/api/status` 增加用时、连续失败次数、下次检查时间与总计。
- JSON 快照改为 `Cache-Control: no-cache`，浏览器每次复核，未变化时由服务器回 304。Caddyfile 已同步修改，部署时需要重新安装 Caddy 配置。
- `FOOTBALL_ALLOWED_ORIGINS` 可设定客户自己的域名（逗号分隔），不再只限 footballknow.art。

## 界面

- 全新设计系统：浅色与深色主题、分组侧栏、固定顶栏、统一的表格与表单样式，手机端改为抽屉导航。
- 首页改为总览仪表板：下一场或进行中的比赛、市场隐含概率、赛季进度、场均进球、胜平负分布、今日比赛、同步状态、积分榜与射手榜。

## 新功能

| 功能 | 入口 | 文件 |
| --- | --- | --- |
| 全站搜索（球队、球员中文／粤语／原名、比赛、页面） | 顶栏，或 Ctrl K、`/` | `public/shell.mjs` |
| 同步监控（25 项任务逐项状态） | `#/status` | `public/status-page.mjs` |
| 球队对比（逐项数据与交锋） | `#/compare` | `public/compare-page.mjs` |
| 所有表格点击表头排序、导出 CSV | 每张表格下方 | `public/table-tools.mjs` |
| 赔率隐含概率与报价水位 | 首页、比赛详情 | `public/insights.mjs` |
| 深色／浅色主题 | 顶栏 | `public/theme.js` |

## 验证

- 已运行：Python 33 项（含新增的同步排程、退避、条件请求）、Node 21 项（含新增的 `insights.test.mjs`）全部通过。
- 已在真实 Chromium 中检查 1440 px 与 390 px 的总览、榜单、比赛详情、同步监控、球队对比、搜索、排序与 CSV 导出，无脚本错误、无页面横向溢出。
- 未运行：`tests/test_backend.py`、`tests/test_leagues.py`（本次环境没有 FastAPI）与 `tests/interface.test.mjs`（没有 jsdom）。部署前请在装有依赖的环境执行 `pytest` 与 `npm test`。
- 未验证：25 项任务对真实来源连续每 60 秒运行的效果。上一版在腾讯云已出现 ESPN 球员榜 403；提高到每分钟后，ESPN、Wikipedia 与书商官网更可能限制访问，上线后请在同步监控观察一天。

## 对外销售前需要处理

本站数据来自 FPL、LALIGA、ESPN、Football-Data、Wikipedia 等公开来源，仓库没有取得这些数据的商业再授权。向客户收费提供前，需要逐一确认各来源的使用条款，或改接有商业授权的数据供应商。
